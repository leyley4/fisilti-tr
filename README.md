# Fısıltı TR – Sessiz Konuşma Arayüzü

The Subvocal Company (YC Fall 2026) fikrinin Türkçe'ye yerelleştirilmiş, tarayıcıda çalışan simülasyonu.

## Özellikler
- 4 kanallı sEMG simülasyonu (dudak, çene, dil, gırtlak)
- Türkçe harf düzeyinde çözümleme (29 harf)
- Türkçe komut sözlüğü ile Levenshtein tabanlı düzeltme
- Komut yürütme (müzik, saat, alarm, ışık, hava, mesaj...)
- Sesli asistan ile ortam sesi karşılaştırması

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. Kurulum gerekmez.
